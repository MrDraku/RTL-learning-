# Smart Washing Machine Controller (Moore FSM)

## Overview

This is my first major RTL design project built using Verilog HDL.

I chose a Smart Washing Machine Controller because it represents a real-world embedded control system where multiple operations, safety conditions, and sequential decisions must work together. It provided the perfect opportunity to learn how an engineering specification is transformed into hardware.

## What This Project Covers

- Moore Finite State Machine (FSM)
- Binary State Encoding
- Sequential Logic Design
- Priority-Based State Transitions
- Asynchronous Reset
- Pause/Resume Mechanism
- Safety and Error Handling
- RTL Design & Functional Verification
## What I Learned

This project taught me that RTL design is much more than writing Verilog. Every block of hardware begins with a specification, which is then translated into states, inputs, outputs, transition logic, and finally verified through simulation.

## Tools Used

- Verilog HDL
- Visual Studio Code
- Icarus Verilog
- GTKWave
