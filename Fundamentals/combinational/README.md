Combinational Logic
This folder contains basic combinational digital logic designs built in Verilog. These modules produce outputs based only on the current inputs, without any internal memory or state.

Focus Areas
Logic gates: AND, OR, NAND, and OR-NAND
Arithmetic circuits: full adder, CLA adder, ALU
Data selection: mux and demux
Comparison and encoding: comparator, priority encoder
Error detection: even and odd parity
Purpose
These designs are used to practice Boolean algebra, signal flow, gate-level modeling, and RTL implementation. They form the foundation for more advanced digital systems and sequential designs.

Verification
Each design is typically validated with a matching testbench and simulated to confirm functional behavior.
